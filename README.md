# pi-skill-implement

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-implement)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**implement** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Implement a piece of work based on a spec or set of tickets.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-implement
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-implement.git ~/.pi/agent/skills/implement

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-implement.git ~/.agents/skills/implement
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:implement
```

Or let Pi automatically route to it based on conversation context and need.
